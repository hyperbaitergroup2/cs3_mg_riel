1. Decomposition: We split the code into the class variables, such as name, health, and damage. After that we split each seperate proccess into their own part, such as attacking, moving, and taking damage.

2. Patter recognition: Actions that are repeated in each turns are the plants attacking the zombies and the zombies attacking the plants.

3. Abstraction: Information the character actually needs are only health, damage, and name.

4. Algorithm Design: We first made the zombie class with the variables and the attack, take damage, and movement. After that we made the plant class with the variables, attack, movemnt, and take damage. After that we made the objects and variables for each class such as plant1, plant2, and zombie1. After that we made the game info and while loop. The while loop checks if the distance is zero before doing/taking damage. Then after enough turns it will break if either side's health reach zero.
